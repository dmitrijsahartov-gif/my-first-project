# Калькулятор показателей ЭхоКГ

Программа для быстрого расчёта ЭхоКГ с телефона: все данные
вводятся **одним сообщением**, затем сразу выдаётся полный отчёт.

## Запуск

```bash
python3 echocg_calculator.py
```

Вставьте блок данных и отправьте **пустую строку**.

Или из файла:

```bash
python3 echocg_calculator.py данные.txt
```

## Формат ввода

Размеры ЛЖ — в **мм**, объёмы — в **мл**, рост — в **см**, вес — в **кг**.

### Режим 1 — по размерам (Teichholz)

```text
Пол: муж
Рост: 178
Вес: 86
КДР: 52
КСР: 34
ТМЖП: 11
ТЗСЛЖ: 10
ЧСС: 68
```

### Режим 2 — готовые объёмы

КДР, ТМЖП и ТЗСЛЖ всё равно нужны для массы миокарда и ОТС:

```text
Пол: жен
Рост: 165
Вес: 60
КДР: 46
ТМЖП: 9
ТЗСЛЖ: 9
КДО: 100
КСО: 40
ЧСС: 70
```

## Что считает

| Показатель | Формула |
|---|---|
| ППТ | Мостеллер |
| ФВ | (КДО − КСО) / КДО × 100% |
| УО / ИУО | КДО − КСО; УО / ППТ |
| МОС / СИ | УО × ЧСС / 1000; МОС / ППТ |
| ММЛЖ / ИММЛЖ | ASE; ММЛЖ / ППТ |
| ОТС | 2 × ТЗСЛЖ / КДР |

Нормы массы миокарда зависят от пола (ASE):

- мужчины — ММЛЖ ≤ 224 г, ИММЛЖ ≤ 115 г/м²;
- женщины — ММЛЖ ≤ 162 г, ИММЛЖ ≤ 95 г/м².
