# Калькулятор показателей ЭхоКГ

Консольная программа на Python для расчёта основных показателей эхокардиографии.

## Что считает

| Показатель | Формула |
|---|---|
| Площадь поверхности тела (ППТ) | Мостеллер: √(рост×вес / 3600) |
| Фракция выброса (ФВ) | (КДО − КСО) / КДО × 100% или Teichholz |
| Масса миокарда ЛЖ | ASE (Devereux) |
| Индексированная масса миокарда | ММЛЖ / ППТ |
| Относительная толщина стенок | 2 × ЗСд / КДР |

## Запуск

```bash
python3 echocg_calculator.py
```

Программа задаёт вопросы на русском языке и выводит результаты с краткой ориентировочной интерпретацией.
