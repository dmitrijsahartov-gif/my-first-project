# ЭхоКГ — калькулятор

Мобильное веб-приложение и Python-скрипт для расчёта основных показателей эхокардиографии.

## Приложение на телефоне (с иконкой)

Откройте `index.html` в браузере телефона, затем добавьте на домашний экран:

- **Android / Chrome** — меню → «Установить приложение» / «Добавить на главный экран»
- **iPhone / Safari** — «Поделиться» → «На экран „Домой“»

Появится иконка **ЭхоКГ**. Все данные вводятся одним сообщением.

### Формат ввода

```text
Пол: муж
Рост: 178
Вес: 86
КДР: 52
КСР: 34
ТМЖП: 11
ТЗСЛЖ: 10
ЧСС: 68
```

Или с готовыми объёмами (`КДО` / `КСО` вместо `КСР`).

## Консольный вариант

```bash
python3 echocg_calculator.py
```

## Что считает

ППТ, ФВ, УО, ИУО, МОС, СИ, ММЛЖ, ИММЛЖ, ОТС.
